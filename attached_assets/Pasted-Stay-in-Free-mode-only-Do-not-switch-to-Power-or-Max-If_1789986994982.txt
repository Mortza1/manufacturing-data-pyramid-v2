4. Directional 3D arrows

Render every connection as a clearly directional arrow:

source → target

Requirements:

visible arrowhead at the target;
source and target endpoints attach to the actual rendered data objects;
connection endpoints must be derived from the current live rendered positions of those objects;
prefer a slightly curved/routed path rather than a straight line through the pyramid when this improves readability;
route the arrow slightly away from pyramid surfaces where practical so it is not easily hidden;
preserve good visibility from different camera angles.

Do not use a plain undirected line.

5. Connections must follow presentation transforms

Connections reference object IDs, not fixed scene coordinates.

Therefore arrows must remain correctly attached when the user:

rotates the pyramid;
zooms;
Explodes / Assembles;
Focuses a level;
Shows Only a level;
hides/shows sectors;
changes Object Size;
changes Data Display density.

If either endpoint is currently hidden because of:

Data Display 1 / 2 / 3;
hidden sector;
Show Only level;

hide that connection arrow temporarily.

Do not delete the stored connection.

When both endpoints become visible again, the arrow must reappear.
