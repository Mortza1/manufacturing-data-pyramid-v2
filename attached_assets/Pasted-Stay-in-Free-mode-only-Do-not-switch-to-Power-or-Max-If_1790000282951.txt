4. Database schema

Use the existing Drizzle/PostgreSQL setup.

Create the minimum database-backed project/version model.

Users

For this non-authenticated course/demo stage, use:

stable UUID ID;
display/name field;
created timestamp;
updated timestamp.

Design it so authentication identifiers can be added later without breaking projects.

Do not treat a browser-supplied name as production-grade authentication.

Projects

stable UUID project ID;
owner/user ID;
project name;
project description;

updated timestamp.
Project Versions

Store:

stable UUID version ID;
project ID;
integer version number;
complete JSONB project snapshot;
snapshot schema version;
optional version note;
created timestamp;
user/creator ID.

Add a uniqueness constraint equivalent to:

Historical version rows are immutable.
